In this chapter you'll render macros, which are custom components within rich text.

== Intro

Occasionally, you may require rich components, even within your rich text. This is enabled via a component type called macros. Macros follow the same pattern as you have seen for other components.

== FactBox macro

In your Enonic project, a `FactBox` macro schema is pre-defined.
It is located in `src/main/resources/cms/macros/factbox/factbox.yaml`.
If you take a closer look at the Léa Seydough bio, you can see how the `factbox` macro is used.

. *Register the factbox macro*, like all other components:
+
.src/components/_mappings.ts
[source,typescript]
----
...
import FactBox from './macros/FactBox';
...
ComponentRegistry.addMacro(`${APP_NAME}:factbox`, {
    view: FactBox,
    configQuery: '{ header }'
});
----
+
NOTE: Macros do not support the regular queries, but you may use `configQuery`. This specifically operates on the form values for the component, and the result will automatically be available in the React component's `config` prop.
+
TIP: You do not need to ask for the macro body, as it is implicitly passed to the macro component.
+
IMPORTANT: Macros must be registered before the adapter prepares the outgoing query. Register the macro in `+_mappings.ts+` so it is available when requests are handled.
+
NOTE: The sample content also uses a `filmography` macro, for instance in the bio of Keanu Reefs. This tutorial does not implement it, so those pages show a notice about the missing macro. Register a component for it in the same way if you want to render it.
