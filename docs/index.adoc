This is a step-by-step tutorial on building and managing https://nextjs.org/[Next.js] sites, using Enonic as your back-end. The combined set of software and tools used in this tutorial is called Next.XP.

TIP: *Just want to see the result?* <<demo#,Run the demo>> to try the finished application without going through the chapters, either locally or in the cloud.

== Intro

Next.XP is an opinionated out-of-the-box integration between Enonic XP and Next.js - ideal for building and maintaining websites.

It offers content editors a familiar and hassle-free way of working with content, using structured content, component based landing pages, and extensive control over the site's URL structure.

When you are done, editors can build and preview pages like this:

.Editors enjoy WYSIWYG editing and live preview, combined with statically generated pages
image::cloud-preview.webp[Content Studio showing a live preview of the front page rendered by Next.js,width=1440]

You will complete the following steps:

* <<enonic-setup#,Set up Enonic>> with sample content
* <<api-primer#,Get familiar with the GraphQL API>>
* <<sites#,Create a site>> and learn about the site concept in Enonic
* <<nextjs-setup#,Create a Next.js app>> from a starter
* <<rendering-basics#,Render content>> based on its type
* <<preview#,Activate live preview>> in Content Studio
* Render <<rich-text#,rich text>> and <<macros#,macros>>
* Build landing pages using <<pages#,pages>>, <<parts#,parts>> and <<layouts#,layouts>>
* <<templates#,Create page templates>>
* <<static#,Generate static pages>>, and update them when content is published
* <<i18n#,Handle multi-language sites>>
* <<deployment#,Deploy to live servers>>

[#prerequisites]
== Prerequisites

Experience with Next.js is nice, but not required. If Enonic is new to you, complete the {intro-tutorial}[introduction to Enonic] before starting this tutorial.

To follow this tutorial you will need:

* https://nodejs.org/[Node.js] {node-minimum} or newer, with npm {npm-minimum} or newer
* https://git-scm.com/[Git], and a GitHub account for the <<deployment#,live deployment>> chapter
* Your favorite code editor

You will install the Enonic CLI in the first chapter.
