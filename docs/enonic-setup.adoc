In this chapter you will create a local Enonic development environment, then create and deploy an Enonic app with sample content.

== Task: Install the Enonic CLI

The Enonic CLI manages local instances of Enonic XP, known as sandboxes, and builds and deploys your apps.

. *Install the CLI* - Follow the https://developer.enonic.com/start[installation instructions] for your operating system.
. *Verify the installation* - Run `enonic -v` in your terminal. It prints the installed CLI version.

== Task: Create and start a sandbox

. *Create a sandbox* - Run this command in your terminal to create a sandbox called `+tutorial_nextjs+`. It works from any folder:
+
[source,shell,subs="attributes+"]
----
enonic sandbox create {sandbox-name} -t essentials -f
----
+
NOTE: `-f` forces the use of default values for the remaining options, which includes the latest version of Enonic XP, and starts the sandbox.

. *Verify that the sandbox is running* - Open http://localhost:8080[http://localhost:8080] in your browser. The Enonic XP Welcome page appears.

Leave the sandbox running in this terminal window. To stop it, press ctrl-c. To start it again, run `+enonic sandbox start tutorial_nextjs+` from any folder.

NOTE: The sandbox has its own content and applications, separate from other tutorials. All sandboxes use the same ports by default, so stop the sandbox of any other tutorial before starting this one.

== Task: Create and deploy your app

Open a new terminal window in the folder where you keep your tutorial projects, for example `enonic-tutorials/`. The commands below create the app in a subfolder of its own.

. *Create a new project* - Use the `Introduction` app as a starter by running this command:
+
[source,shell,subs="attributes+"]
----
enonic project create {app-id} -r tutorial-intro -s {sandbox-name} -d {enonic-folder} -f
----
+
This command will:
+
* use the GitHub repo `github.com/enonic/tutorial-intro` as a starter
* create an app called `{app-id}`
* link it to the `+tutorial_nextjs+` sandbox
* place the project in a new folder called `{enonic-folder}`

. *Deploy the application* - Run these commands to build and run your application:
+
[source,shell,subs="attributes+"]
----
cd {enonic-folder}
enonic dev
----
+
The last command builds and deploys the app to the sandbox, then watches the code for changes and rebuilds as you work on it.

. *Verify the deployment* - In `dev` mode the CLI keeps watching for changes, so the build process never exits. This is expected behavior. When your terminal shows output like the following, the app has been built and deployed:
+
[source,text,subs="attributes+"]
----
> Task :deploy
Deploying 'nextjs.jar' to '.../.enonic/sandboxes/{sandbox-name}/home/deploy'
BUILD SUCCESSFUL in 1m 16s
Waiting for changes to input files...
----
+
On its first deployment, the app creates the `Intro Project` content project and publishes its sample content.

Leave `enonic dev` running in this terminal window as well. To stop it, press ctrl-c. To resume the tutorial later, start the sandbox and then run `enonic dev` from the `{enonic-folder}` folder again.

== Task: Open the admin dashboard

The sandbox has a web interface for managing applications and content.

. *Open the Welcome page* - Go to http://localhost:8080[http://localhost:8080] in your browser.
+
.Welcome page
image::xp-boot.png[The XP boot page,width=1280]
+
The Welcome page provides an overview of the sandbox, including installed applications and {xp-docs}/{xp-docs-version}/config[standard configuration files]. `Intro` should be in the list, together with the other applications that were installed when you created the sandbox.

. *Log in* - Click btn:[Log In as Guest] to open the XP admin dashboard.
+
.The XP admin dashboard
image::xp-dashboard.webp[The XP admin dashboard,width=1280]
+
The center menu, known as the `XP menu`, lets you navigate between admin tools.
Applications can add admin tools as extensions.
+
NOTE: If things don't look exactly the same, don't worry. In every new version of XP the background picture gets updated. Also, the admin dashboard is automatically localized, based on your browser's preferred language.

== Task: Open Content Studio

https://market.enonic.com/vendors/enonic/content-studio[Content Studio] is the editorial interface used to create and manage content. It was pre-installed from https://market.enonic.com[Enonic Market] as a part of the `Essentials` template when you started the sandbox, and can be accessed from the XP menu.

. *Launch Content Studio* - Click btn:[Content Studio] in the XP menu.
+
The first time your application was deployed to the sandbox, it automatically created a content project called `Intro Project` (id `intro`) and populated it with content. Since this is the only available project at the moment, Content Studio opens it automatically.
+
TIP: The current project is shown at the top of Content Studio.

. *Verify the sample content* - Content Studio lists the sample content items:
+
image::content-studio-moviedb.png[Movie DB in Content Studio,width=1280]
+
NOTE: Some of the content items will have a default preview. That's okay for now - you'll customize the preview later.
