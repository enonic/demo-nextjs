= Page templates
:toc: right
:imagesdir: media/
:sourcedir: ../src

Thus far, page rendering has been based on mappings, or editorially composing one page at a time. In this chapter you'll learn how to make page templates - and reuse them across multiple content items.

== Task: Add a movie details part

To complete this chapter, you'll need one final part for presenting movie details. The content type and content for movies already exist in Enonic.

. *Check the part descriptor* - Verify that the Enonic app has the `movie-details` part descriptor, same procedure as before:
+
.src/main/resources/cms/parts/movie-details/movie-details.yaml
[source,yaml]
----
kind: "Part"
title: "Movie Details"
description: "Show details of a movie"
form: [ ]
----

. *Redeploy the Enonic app* - This is only needed if you made any changes, and happens automatically if you started `enonic dev`.

. *Add the Movie query and view* in Next.js:
+
.src/components/parts/MovieDetails.tsx
[source,typescript]
----
include::{sourcedir}/components/parts/MovieDetails.tsx[]
----

. *Update the component mappings*:
+
.src/components/_mappings.ts
[source,typescript,options="nowrap"]
----
import MovieDetails, {getMovie} from './parts/MovieDetails';

// Part mappings
ComponentRegistry.addPart(`${APP_NAME}:movie-details`, {
    query: getMovie,
    view: MovieDetails
});

----
+
The part is now available in Content Studio. You'll put it to use in the next task.

== Task: Create a template

With the new component registered, put it to use.

. *Edit your favorite movie* - In Content Studio, select and edit your favorite movie (or choose "No time to deflate" if you have no favorites).

. *Add the part to the page* - Open the context panel by pressing its icon in the top right screen corner, select `Page` in the widget dropdown, then `Main` in the Template dropdown. Add the `Movie Details` part to the page: drag `Part` from the `Insert` tab into the region and pick it in the part dropdown.
+
image::movie-details.webp["No time to deflate, configured with movie-details part",width=1440]
+
You now have a single movie nicely presented, but it would be cumbersome to configure each movie like this manually. Page templates to the rescue.

. *Select the page component* - In the `Page` tab of the form on the left, select the page (root) component named `Main`.
+
image::movie-page.webp["The Main page component selected in the Page tab of a movie",width=1440]

. *Save as template* - Right-click the component and select `Save as Template` from the context menu.
+
This creates a new page template content item, and opens it in a new tab for editing.

. *Give your template a better name*, such as "Movie details", and click `Save`. The template already supports the `Movie` content type.
+
image::movie-template.png["Content item of type template, configure to support movie items",width=1440]

. *Publish the changes* - Publish both the movie and the new page template (`Mark as ready` -> `Publish now` for each).

. *Verify the result* - Visit other movie items. They now render automatically, using the template.

== Summary

You've added a `MovieDetails` part and saved a page as a template, so every movie is rendered with the same page definition.
