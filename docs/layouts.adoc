= Layouts
:toc: right
:imagesdir: media/
:sourcedir: ../src

In this chapter you will add a two-column layout, which lets editors place components side by side.

Layouts are essentially parts with an extra trick up their sleeve: regions. This means that layouts may host other components, and build rich page structures.

== Task: Add a layout to Enonic

Adding layouts is more or less identical to adding pages and parts.

. *Check the layout descriptor* - Verify that the Enonic app has the `2-column` layout descriptor at:
+
.src/main/resources/cms/layouts/2-column/2-column.yaml
[source,yaml]
----
kind: "Layout"
title: "2 columns"
description: "Provides left and right regions"
form: [ ]
regions:
  - "left"
  - "right"
----
+
NOTE: Like a page, layouts may declare named regions.

. *Redeploy the Enonic app* - This is only needed if you had to change it, and happens automatically if you started `enonic dev`.

== Task: Add layout rendering to the front-end

Move over to the Next.js app, and add the component that renders the layout.

. *Add the front-end layout component*:
+
.src/components/layouts/TwoColumnLayout.tsx
[source,typescript]
----
include::{sourcedir}/components/layouts/TwoColumnLayout.tsx[]
----
+
And its CSS module:
+
.src/components/layouts/TwoColumnLayout.module.css
[source,css]
----
include::{sourcedir}/components/layouts/TwoColumnLayout.module.css[]
----
+
NOTE: This is an example of using CSS modules. For more details visit the https://nextjs.org/docs/app/getting-started/css[Next.js style documentation].

. *Register the component* - Add these new lines to the `+_mappings.ts+` file:
+
.src/components/_mappings.ts
[source,typescript,options="nowrap"]
----
import TwoColumnLayout from './layouts/TwoColumnLayout';


// Layout mappings
ComponentRegistry.addLayout(`${APP_NAME}:2-column`, {
    view: TwoColumnLayout
});
----
+
NOTE: This specific layout does not need any additional data, hence no query or processor.

. *Verify the result* - In Content Studio, add the layout to a page: drag `Layout` from the `Insert` tab into the region and select `2 columns` in the `Inspect` tab. Then add parts inside the `left` and `right` regions of the layout.
+
By combining layouts and parts, the potential of the page editor starts to show:
+
image::layout-part-text.png[Front page with a paragraph above a two-column layout holding a child list and a paragraph,width=1440]

You've added a `2-column` layout with `left` and `right` regions, and used it to place components side by side on a page.
